## 🎯 Quick Reference

### Common Commands

**Start local server (Python):**
```bash
python -m http.server 8000
```

**Start local server (Node.js):**
```bash
npx http-server -p 8000
```

**Deploy to Netlify:**
```bash
# Drag and drop folder to netlify.com
```

**Deploy to Vercel:**
```bash
vercel
```

**Main HTML**: `index.html`
